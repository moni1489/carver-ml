# Статус проекта (на 2026-11-14)

## Итог по bbox B, 2021 (признаки NDVI + SWIR + history)

Источник: `reports/bboxB_2021/` (`summary_2021.json`, `class_metrics_2021.csv`, `buffer_sweep_summary_2021.csv`), запуск 2026-11-14, `config_sha256` b85ecb2c…

**Признаки:** `features: [ndvi, swir, history]`. На каждую из 22 дат берутся NDVI, B06 (SWIR1), B07 (SWIR2) и NDMI (88 признаков). К ним добавлены 3 признака history: была ли точка пашней по CDL 2019 и 2020 и сумма этих двух флагов, всего 91 признак. CDL 2021 в признаки не входит: это метки. Модель: RandomForest, пространственная CV 3 × 3, основной буфер 30 px, решающее правило argmax. Отчёты NDVI + SWIR лежат в `reports/_archive/bboxB_2021_ndvi_swir/`. Сравнение вариантов: `reports/bboxB_2021/experiments/history/`.

| Метрика | Сельхозпиксели CDL | Весь bbox |
|---|---|---|
| Accuracy | **0,890** | **0,861** |
| Тривиальный baseline (самый частый класс fallow_idle) | 0,335 | 0,252 |
| Macro F1, 5 сельхоз-групп | 0,731 | 0,705 |
| Macro F1 без small_grains (4 группы) | 0,896 | 0,864 |

F1 по классам (буфер 30 px):

| Группа | F1 на сельхозпикселях | F1 на bbox | Precision bbox | Recall bbox | Пикселей |
|---|---|---|---|---|---|
| alfalfa | 0,849 | 0,797 | 0,779 | 0,817 | 65 225 |
| cotton | 0,887 | 0,856 | 0,807 | 0,911 | 39 231 |
| small_grains | 0,070 | 0,067 | 0,145 | 0,044 | 942 |
| corn | 0,930 | 0,918 | 0,894 | 0,942 | 60 083 |

**fallow_idle проходит порог precision 0,7 по bbox: 0,865** (было 0,695 без history). Ложных fallow 11 889 (было 29 713). Из них по CDL относятся к other 5 808 (было 24 553), остальные 6 081 — это перепутанные культуры. В экспорте fallow больше не помечен как низкодостоверный. F1 alfalfa, cotton и corn изменились не больше чем на 0,002. **small_grains по-прежнему практически не распознаётся** (F1 0,07, всего 942 пикселя, 0,3 % bbox).

**Ограничение history:** признак требует CDL прошлых лет, поэтому работает только в США. Для регионов без CDL (например, vko) модель с history неприменима.

С 30 на 150 px macro F1 (4 группы) падает на 0,004 на сельхозпикселях и на 0,008 по bbox при пороге остановки 0,15. Без history при тех же буферах accuracy по bbox падала с 0,774 до 0,705, а precision fallow с 0,695 до 0,575. С history результат почти не зависит от буфера.

### Перенос на 2020 (вне основной CV)

Источник: `D:\carver-data\transfer_2020\transfer_2020.json`. Модель **NDVI + SWIR без history** обучена на всех пикселях 2021 и проверена на HLS 2020 того же bbox против CDL 2020. Даты 2020 подставлены на места дат 2021: бралась ближайшая по месяцу и дню, не дальше 8 дней, иначе NaN.

| | CV 2021 | Перенос 2021 → 2020 | CV внутри 2020 |
|---|---|---|---|
| Accuracy, сельхозпиксели | 0,855 | 0,856 | 0,851 |
| Accuracy, bbox | 0,774 | 0,698 | 0,767 |
| Precision fallow, bbox | 0,695 | 0,528 | 0,660 |

Культуры переносятся на другой год без потери точности. Слабое место — залежь против пустыни. Тот же bbox: это проверка другого года, а не другого региона. С history перенос не проверен: для признаков 2020 нужен CDL 2018, его архива нет.

Выборка: сетка 578 × 580 = 335 240 пикселей. Внутри lon/lat-рамки bbox с меткой CDL 331 092, после фильтра «чистых дат ≥ 11 из 22» осталось 331 054. Из них сельхозпикселей по CDL 248 964. Из 27 дат в модель вошли 22. Выпали 3, 10, 19 июля, 11 августа и 23 октября: в bbox меньше 50 % чистых пикселей.
