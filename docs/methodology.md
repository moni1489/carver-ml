# Методология: Field Shift (Аризона, 2021)

Written for: жюри хакатона и технически подкованные участники, которые будут читать код.

## 1. Задача и регион

Проект «Field Shift» (NASA Space Apps) оценивает, какие культуры выращивались на сельхозполях и как долго почва оставалась голой между посевами. Модель работает с пикселями спутниковых снимков, а не с отдельными полями.

**Регион:** Аризона, район к юго-востоку от Феникса (ориентировочно). Границы области интереса задаются в `configs/ml.yaml`:

```yaml
bbox: [-111.9, 32.9, -111.5, 33.2]   # [min_lon, min_lat, max_lon, max_lat]
```

Координаты приблизительные. В конфиге помечено, что их нужно проверить по карте CDL перед реальным запуском.

**Период:** 2021 год, сезон 1 апреля – 31 октября (`temporal`).

## 2. Данные

| Источник | Что используем | Детали |
|---|---|---|
| HLS L30, версия 2.0 (NASA LP DAAC) | Оптические отражения Landsat 8/9 (30 м), полоса Fmask для маски облаков | Загрузка через CMR/earthaccess |
| CDL 2021 (USDA NASS) | Метки культур по пикселям, разрешение 30 м | Используется как разметка для обучения и оценки |

**Даты снимков HLS (8 сцен, 2021):** 21 апреля, 16 мая, 1 июня, 24 июня, 26 июля, 27 августа, 21 сентября, 14 октября. Сцены выбраны по одной на дату с предварительным отбором по облачности через CMR.

**Ограничение по облачности:** порог `max_cloud_pct: 20` — доля облаков внутри bbox по Fmask.

## 3. Метод

### 3.1. Признаки

Для каждого пикселя считается **NDVI** по каждой из 8 дат. Итоговый вектор признаков — 8 значений NDVI на пиксель. Порог `bare_soil_ndvi: 0.2` используется отдельно: NDVI ниже него считается голой почвой при расчёте дней без растительности (`bare_soil`).

Пиксели с облаками по Fmask исключаются из обучения и предсказания.

### 3.2. Модель

**RandomForest** классифицирует каждый пиксель по классу культуры. Обучение и предсказание идут покадрово по пикселям внутри bbox.

### 3.3. Группировка классов CDL

Исходные коды CDL объединены в шесть групп, чтобы классы с малым числом пикселей не разбивали обучение:

| Группа | Коды CDL | Комментарий |
|---|---|---|
| Люцерна (alfalfa) | 36 | Многолетняя культура, видна по NDVI в течение всего сезона |
| Хлопок (cotton) | 2 | |
| Мелкие зерновые | 22, 21 | Пшеница (22) и ячмень (21) |
| Кукуруза (corn) | 1 | |
| Залежь / простой (fallow/idle) | 61 | Сельхозземля без посева в сезоне |
| Прочее | Все остальные коды, включая shrubland 152, grassland 176, developed 121–123, barren 131 | Не сельхоз; сюда попадают кустарник, пастбища, застройка и голая земля |

Группа «Прочее» нужна, чтобы модель не теряла пиксели вне сельхоза и не выдавала им ложную культуру.

### 3.4. Валидация

Валидация выполняется на **пространственных блоках внутри bbox с буфером**: блок целиком уходит либо в обучение, либо в тест, а вокруг тестового блока есть буферная зона, из которой обучающие пиксели исключаются.

Случайное разбиение по пикселям **не используется**: соседние пиксели почти одинаковы, и случайная выборка завысила бы качество из-за утечки. Размер блоков и ширина буфера пока не зафиксированы в конфиге; их значения будут записаны вместе с результатами baseline.

## 4. Метрики

Считаются две F1-оценки, и они не смешиваются:

1. **F1 по сельхозпикселям** — только пиксели, где по CDL есть сельхоз-группа (люцерна, хлопок, мелкие зерновые, кукуруза, залежь).
2. **F1 по всему bbox** — все пиксели, включая группу «Прочее».

Вторая метрика может быть выше за счёт небсельхозных пикселей, которые легко отличить от посевов, поэтому по ней нельзя судить о качестве определения культур.

## 5. Ограничения

- **Только Аризона.** Модель не переносится на другие регионы без повторного обучения. Поле `domain_shift` относится к **ячейке H3 разрешения 5** в экспорте для Furrow. Внутренний контракт `FieldAnalysis` описывает поле и не является источником этого значения.

Значение не задаётся вручную. Оно вычисляется из конфига региона: `domain_shift = not labels_available`, где `labels_available` — наличие меток CDL для валидации в регионе (`AZ: true`, `VKO: false`). Вычисляет пайплайн при сборке экспорта.

Метрики F1 не применяются к ячейкам с `domain_shift = true`: для них нет меток, по которым можно было бы проверить модель. Поэтому поле показывает, где качество модели проверено, а где нет. Для Аризоны значение всегда `false`.
- **Только 2021 год.** Другие годы не проверялись.
- **Точность по отдельным полям не оценивалась.** Результаты — оценка на уровне пикселей и групп, а не по конкретным участкам фермеров.
- **Модель не предсказывает будущее.** Она описывает прошлый сезон 2021 года по снимкам, ничего не прогнозирует.
- **Метки CDL имеют собственную ошибку.** CDL — тоже модельный продукт USDA, а не эталон. Ошибки разметки попадают в метрики, и итоговые F1 отражают согласие с CDL, а не истинное состояние полей.
- **Облака и тени.** Пиксели с облаками исключаются, но тени и частичная облачность по Fmask могут пройти фильтр.
- **Восемь снимков на сезон.** Редкие съёмки ограничивают различение культур с похожим сезонным циклом.

## 6. Источники данных: NASA и не-NASA

Проект использует данные NASA как основу и одну не-NASA разметку для обучения и проверки. Ниже указано, что откуда и для чего. Если источник не используется в нашем ML-пайплайне, это написано явно.

### Данные NASA

| Источник | Что это | Роль в проекте | Ссылки |
|---|---|---|---|
| HLS L30 v2.0 (`HLSL30`), NASA LP DAAC | Гармонизированные отражения Landsat 8/9 с разрешением 30 м, с полосой качества Fmask | Основной вход ML: полосы B04 (красный) и B05 (ближний ИК) для NDVI, Fmask для маски облаков и теней. 8 дат 2021 года | [Страница продукта LP DAAC](https://lpdaac.usgs.gov/products/hlsl30v002/), [DOI 10.5067/HLS/HLSL30.002](https://doi.org/10.5067/HLS/HLSL30.002) |
| NASA POWER | Метеорологические и климатические ряды NASA (LaRC) | **Не используется в нашем ML-пайплайне.** Нужен слою Furrow (климат по ячейкам H3), см. README Furrow | [Сайт POWER](https://power.larc.nasa.gov/), [Документация](https://power.larc.nasa.gov/docs/) |

### Не-NASA дополнения

| Источник | Что это | Роль в проекте | Ссылки |
|---|---|---|---|
| CDL 2021 (Cropland Data Layer), USDA NASS | Карта культур США, 30 м | Метки для обучения и проверки. Это не эталон, а модельный продукт со своей ошибкой | [Описание CDL](https://www.nass.usda.gov/Research_and_Science/Cropland/SARS1a.php), [CropScape](https://nassgeodata.gmu.edu/CropScape/) |
| SoilGrids, ISRIC | Глобальные цифровые карты свойств почвы | **Не используется в нашем ML-пайплайне.** Нужен слою Furrow (почва по ячейкам H3), см. README Furrow | [ISRIC: SoilGrids](https://www.isric.org/explore/soilgrids), [soilgrids.org](https://soilgrids.org) |

Что делает каждый источник для результата:
- Отражения HLS дают признаки. Метки CDL определяют, чему модель учится и по чему её оценивают. Поэтому метрики измеряют согласие с CDL, а не с реальным состоянием полей (см. раздел «Ограничения»).
- POWER и SoilGrids не влияют ни на наши признаки, ни на наши метрики. Они перечислены, потому что выход экспортируется в Furrow, который их использует.
